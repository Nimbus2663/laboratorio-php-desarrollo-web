Este paquete contiene los ejemplos practicos y laboratorios solicitados en la presentacion:

- Verificacion de instalacion de PHP con `phpinfo.php`.
- Practica 1 con `hola_mundo.php`.
- PHP embebido en HTML con `php_embebido.php`.
- Variables con `variables.php`.
- Tipos de datos, casting, `settype`, `gettype`, `var_dump` y constantes con `tipos_casting_constantes.php`.
- Salida con formato con `salida_formato.php`.
- Operadores matematicos y precedencia con `operaciones_matematicas.php`.
- Comentarios con `comentarios.php`.
- Formulario HTML y `$_REQUEST` con `formulario_request.php`.
- Laboratorio 1: conversion de pulgadas a centimetros con `conversor_pulgadas.php`.
- Problema 2: calculadora con suma, resta, multiplicacion y redondeo de decimales con `calculadora.php`.

## Como ejecutarlo en WampServer o XAMPP

1. Copie la carpeta `laboratorio_php` dentro de la carpeta publica del servidor:
   - WampServer: `C:\wamp64\www\laboratorio_php`
   - XAMPP: `C:\xampp\htdocs\laboratorio_php`
2. Inicie Apache desde WampServer o XAMPP.
3. Abra el navegador en:

```text
http://localhost/laboratorio_php/
```

4. Use la pagina `index.php` para abrir cada ejemplo.

## Tecnologia utilizada

- PHP 8 o compatible.
- Servidor local Apache mediante WampServer o XAMPP.
- HTML5.
- CSS3.
- Editor recomendado: Visual Studio Code.
